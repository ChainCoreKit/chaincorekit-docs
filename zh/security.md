# 安全模型

ChainCore Kit 的核心原则是**本地优先**：一切涉及私钥与助记词的运算都在你的浏览器里完成。

## 私钥/助记词不出本机

- 助记词与私钥的生成、钱包派生、交易签名，全部在**浏览器本地内存**中进行。
- 这些敏感数据**不上传、不存储、不出本机**，也不写入 localStorage。
- 关闭或刷新页面后，本次生成的私钥/助记词即从内存中消失、无法找回——所以务必先导出或抄写保存。

## 结果默认打码

- 私钥/助记词在结果中默认打码，点击眼睛图标才明文显示。
- 请在无人窥屏、无录屏/远程的**安全环境**下查看与保存。
- 二维码只对**地址**生成，可安全用于接收测试币；**切勿**为私钥生成二维码。

## 导出含私钥文件的风险

- 导出「含私钥表格」**默认加密**：设一个密码（至少 8 位），得到 `.ccbackup.json` 文件。密钥由密码经 scrypt 推导，内容用 AES-256-GCM 加密；格式是公开的，离开本站也能用标准工具解开。
- 还原：在任一钱包页点「解密备份」，选择文件、输入密码，即可下载回原来的表格。**密码丢了就解不开**，本站也帮不了你。
- 仍可选择导出明文：明文文件任何人拿到都能**完全控制**这些钱包，只在安全环境下操作，妥善保管并及时删除。

## 剪贴板

- 复制私钥 / 助记词后，**45 秒自动清空剪贴板**（提示里会写明）。剪贴板历史、剪贴板管理器、跨设备同步都能读到它，粘贴完就不该再留着。
- 期间在本站复制了别的内容，就不会再去清空 —— 不抹掉你后来复制的东西。
- 页面不在前台时浏览器不允许写剪贴板，会等你回到页面再清。

## 自定义 RPC 与 API Key

- 地址里带 API Key 的 RPC 端点**不会保存到本地**（Infura、Alchemy、QuickNode 等，或带 `?apikey=`、`user:pass@` 的地址），刷新后需重新填写。不带 Key 的公共节点照常记住。

## 写操作的安全流程

写操作（转账、合约写函数、部署）遵循固定流程，任何一步都不跳过：

**参数预览 → Gas 预估 → 用户确认 → 钱包签名 → pending → 结果**

- 未连接钱包时，写按钮显示「连接钱包后可用」，不会静默执行。
- 高危操作会有二次确认：`transferOwnership`、`renounceOwnership`、`selfdestruct`、合约升级、`setApprovalForAll`，以及权限类的 `grantRole`、`changeAdmin`、`setOwner`。
- 签名前请核对**地址、金额、网络**三要素。

## 靓号地址：2022 年的 Profanity 事故

如果你的靓号地址（如以 `0x0000…` 开头）是 **2022 年 9 月之前**用 `profanity` 这个工具生成的，**请立即视为已泄露并转移资产**。

- 该工具用 32 位随机种子去初始化随机数发生器，私钥的实际取值空间从 2²⁵⁶ 塌缩到约 2³²。
- 后果是**可以从公开地址反推出私钥**。2022 年 9 月该缺陷被大规模利用，多个靓号地址被盗。
- 判断依据是**生成工具与时间**，不是地址长得好不好看——同样的前缀，用安全工具生成就没有这个问题。

ChainCore Kit 的靓号与钱包生成始终使用浏览器的密码学安全随机源（`crypto.getRandomValues`）取满 256 位熵，不做任何截断；在不支持该随机源的环境下会直接拒绝生成，而不是退回弱随机。

## 站点本身的防护

- 本站禁止被嵌入其他网页（防点击劫持：别人的页面无法把这里套进一个透明框，诱导你点按钮），并限制页面只能从本站加载脚本。
- 某个工具出现问题时，维护者可以不重新部署就把它临时下线，或在页面顶部挂出公告。看到「该工具已临时下线维护」时请稍后再来，已经签名发出的交易不受影响。

## 使用建议

- 优先在**测试网**（如 Sepolia）演练后再上主网。
- 大额操作前先用小额验证流程。
- 对来源不明、未在区块浏览器验证的合约 ABI 保持警惕。
- 靓号等「碰撞生成」的地址，安全性取决于生成工具与环境，务必本地生成、离线保存（见上方 Profanity 事故）。
