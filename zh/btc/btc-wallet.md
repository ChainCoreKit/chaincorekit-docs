# 生成 BTC 钱包（Generate BTC Wallet）· BTC

> 本地批量生成比特币钱包：一条 BIP39 助记词按所选地址类型的 BIP 路径真实派生多个地址，支持 Legacy / Nested SegWit / Native SegWit / Taproot 四种类型，也支持用已有 WIF 私钥导入。私钥不出本机。

## 什么时候用

- 需要一批比特币测试地址做开发、测试或演练。
- 想一次生成多个指定类型的地址（如 Native SegWit `bc1q…` 或 Taproot `bc1p…`）。
- 手上已有 WIF 私钥，想还原出对应地址。

> ⚠️ 私钥仅在本地内存中用于本次操作，**不上传、不存储、不出本机**。先读[安全模型](../security.md)。

## 使用步骤

### 方式一：随机批量生成

1. 选择**生成模式**：
   - **同一助记词派生**：一条 BIP39 助记词按所选地址类型的路径连续派生多个地址，备份**这一条助记词**即可恢复全部地址。
   - **各自独立助记词**：每个钱包各自一条助记词与独立私钥，彼此无关联，需**分别备份每条助记词**。
2. 选择**地址类型**：
   - **Native SegWit（`bc1q` 开头）**：当前主流格式，手续费低、兼容性好，不确定就选它。
   - **Taproot（`bc1p` 开头）**：较新格式，隐私与脚本能力更强。
   - **Nested SegWit（`3` 开头）**：兼容旧钱包的过渡格式。
   - **Legacy（`1` 开头）**：最老的格式，兼容性最广但手续费偏高。
3. 设置**派生地址数量**（≤ 100）。
4. （可选）展开**高级 · 推导路径**，调整 `account` 与起始 `index`，也可填写 BIP39 passphrase。路径前缀随地址类型变化：Legacy `m/44'`（BIP44）、Nested SegWit `m/49'`（BIP49）、Native SegWit `m/84'`（BIP84）、Taproot `m/86'`（BIP86）。
   四种路径都是**真实的 BIP32 派生**——包括 Taproot 的 BIP86，同一条助记词在任意兼容钱包都能恢复出相同地址。
5. 点击**立即生成**，结果表列出地址、私钥（默认打码）。

> **恢复凭据是助记词**：同一助记词派生模式下，抄好这一条助记词（以及填过的 passphrase）即可在任意兼容钱包恢复全部地址。私钥（WIF）可单独备份，但泄露某一把只影响对应的那个地址。

### 方式二：自定义私钥创建

1. 切到**自定义私钥创建**标签。
2. 在文本框输入 WIF 私钥，**一行一个**，可批量粘贴。
3. 点击**立即创建**还原对应地址。

> 仅支持 **WIF 私钥**导入；导入后无法使用「派生地址数量」「推导路径」等高级选项。

> **BIP39 passphrase（选填）**：又称「第 25 个词」。留空即标准派生；一旦填写，
> 同一条助记词会派生出**完全不同、且互不相通**的一组钱包。写错一个字符不会报错，
> 只会安静地给出别的地址；请与助记词**分开保管**，丢失后仅凭助记词无法找回资产。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 生成模式 | `同一助记词派生` / `各自独立助记词` |
| 地址类型 | Native SegWit（bc1q）/ Taproot（bc1p）/ Nested SegWit（3）/ Legacy（1） |
| 派生地址数量 | 1–100 |
| 账户 Account | 推导路径中的 `account'`，默认 0 |
| 起始 index | 路径末段起始值，默认 0 |
| BIP39 passphrase | 选填。留空即标准派生；填了就是另一组钱包，须与助记词分开保管 |
| 导入内容 | WIF 私钥，一行一个 |
| 输出 | 地址、私钥（WIF）；支持复制、导出（仅地址 / 含私钥）、批量选择 |

## 注意事项 & 常见坑

- **数量上限 100**：一次最多生成 100 个地址。
- **passphrase 是助记词的一部分**：换一个 passphrase 就是完全不同的一组钱包，写错不会报错、只会给出别的地址；丢了它，仅凭助记词无法找回资产。
- **私钥导入仅支持 WIF**：其他格式暂不受理。
- 结果**离开或刷新即丢失**，务必先导出或抄写保存。
- 主网真实资产请务必核对地址类型再接收，格式错误会导致无法找回。

## 安全提示

- 私钥默认打码，点击眼睛图标才显示，请在**安全环境**下查看与保存。
- **导出含私钥表格**会写出明文文件，任何人拿到都能完全控制这些钱包——操作前会二次确认，导出后请妥善保管并及时删除。
- 敏感数据不写入 localStorage，关闭页面即从内存清除。
