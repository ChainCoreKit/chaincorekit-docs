# BTC 余额批量查询（Balance Checker）· BTC

> 粘贴多个比特币地址，一次性批量查询余额，支持主网 / 测试网，单次最多 200 个地址。

## 什么时候用

- 手上有一批地址，想快速核对各自余额。
- 归集或盘点前，先看看哪些地址有余额。
- 对账：批量核对生成或导入的地址是否收到资金。

## 使用步骤

1. 选择网络：**主网** 或 **测试网**。
2. 在文本框粘贴地址，**每行一个**，单次最多 200 个。
3. 点击**查询**，余额结果显示在下方结果区。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 网络 | 主网 / 测试网 |
| 地址 | 每行一个（Legacy / SegWit / Taproot 均可），单次 ≤ 200 |
| 输出 | 各地址对应的余额 |

## 注意事项 & 常见坑

- **单次上限 200 个地址**，超出请分批查询。
- 主网与测试网地址不要混填，请先选对网络。
- 余额为链上快照，未确认交易可能未计入，确认后重查即可更新。
