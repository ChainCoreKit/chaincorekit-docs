# PSBT 解码（PSBT Decode）· BTC

> 本地解析 PSBT（BIP-174），查看输入 / 输出 / 手续费与签名进度。仅解码，不签名。

## 什么时候用

- 拿到一份待签名的 PSBT，想在签名前看清它到底要花哪些 UTXO、转给谁、手续费多少。
- 核对多签或硬件钱包流程中，某份 PSBT 目前收集了多少签名。
- 排查 PSBT 是否符合预期，避免误签。

## 使用步骤

1. 选择网络：**主网** 或 **测试网**。
2. 在文本框粘贴 PSBT，支持 **Base64**（`cHNidP8…`）或 **hex**（`70736274ff…`）。
3. 解码结果自动显示：输入、输出、手续费与签名进度。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 网络 | 主网 / 测试网 |
| PSBT | Base64（`cHNidP8…`）或 hex（`70736274ff…`） |
| 输出 | 输入列表、输出列表、手续费、签名进度 |

## 注意事项 & 常见坑

- **仅解码，不签名**：本工具不会对 PSBT 做任何签名或广播。
- 选对网络才能正确解析地址形态；主网 / 测试网前缀不同。
- 手续费 = 输入总额 − 输出总额；若字段缺失可能无法算出精确费率。
- 解码结果仅供核对，最终以你自己的签名钱包展示为准。
