# UTXO 查询（UTXO Lookup）· BTC

> 查看比特币地址的未花费输出（UTXO）明细，支持主网 / 测试网，单次最多 20 个地址。

## 什么时候用

- 想看某地址当前有哪些 UTXO，用于组交易或估算可花费金额。
- 排查资金构成：是集中在一笔大 UTXO，还是分散成许多零钱。
- 批量核对多个地址的 UTXO 情况。

## 使用步骤

1. 选择网络：**主网** 或 **测试网**。
2. 在文本框粘贴地址，**每行一个**，单次最多 20 个。
3. 点击**查询**，UTXO 明细显示在下方结果区。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 网络 | 主网 / 测试网 |
| 地址 | 每行一个（Legacy / SegWit / Taproot 均可），单次 ≤ 20 |
| 输出 | 各地址的 UTXO 明细列表 |

## 注意事项 & 常见坑

- **单次上限 20 个地址**，超出请分批查询。
- 主网与测试网地址不要混填，请先选对网络。
- UTXO 是链上快照，新交易确认后需重新查询才会更新。
