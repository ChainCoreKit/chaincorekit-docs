# Token 检查（Token Inspector）· Solana

> 读取 Mint 账户，看清总量、精度、增发与冻结权限，以及 Token-2022 的扩展字段。

## 什么时候用

- 拿到一个 Token 地址，想先确认**还能不能增发**、**能不能被冻结**。
- 遇到 Token-2022 的代币，想知道它挂了哪些扩展（转账费、永久委托、转账钩子等）。
- 对账时需要精确的 supply 与 decimals，而不是前端展示过的四舍五入值。

## 使用步骤

1. 选网络（Mainnet Beta / Devnet / Testnet）。公共主网端点限流较紧，频繁查询建议在「自定义 RPC」里填自己的端点。
2. 填 **Mint 地址**（base58）。
3. 点**查询**。

## 输出说明

| 字段 | 含义 |
| --- | --- |
| 总量 | 按 decimals 换算后的值，同时给出原始最小单位 —— 后者才是链上事实 |
| 精度 | decimals |
| 增发权限 | 有地址 = 该地址可继续增发；**已放弃（None）= 永远不能再增发** |
| 冻结权限 | 有地址 = 该地址可冻结任意持有者的账户；已放弃 = 不能冻结 |
| 扩展 | 仅 Token-2022。已收录的扩展给出解码后的字段，未收录的给出原始字节 |

## 注意事项 & 常见坑

- **「已放弃」和「没读到」是两回事。** 权限为 None 是一条确定的正面结论（不可再增发 / 不可冻结），页面会用绿色明确标出，而不是留空让你猜。
- **别把 Token 账户（ATA）当成 Mint 填进来。** 两者的 owner 都是 Token Program，但 ATA 存的是「某人持有某个 Token 的余额」。按 Mint 的布局去读 ATA，会把它前 32 字节的 mint 地址读成「增发权限」——一个看起来完全合法的错值。本工具会先判定账户类型，识别出 ATA / Multisig 时直接告诉你填错了。
- **本页不给安全评分。** 同一个字段在不同项目里的含义相反：保留增发权限对稳定币是必需的，对一个声称固定总量的代币则是风险信号。工具只把事实摆出来。
- **未收录的扩展会照实标注。** Token-2022 的扩展类型还在增加，遇到不认识的会标为「未收录」并给出原始字节，不会套用一个相近的已知扩展。**未收录不等于有问题。**
