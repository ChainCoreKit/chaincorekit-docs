# Solana 余额查询（Solana Balance）

> 一次查出某个地址的 SOL 余额与全部代币持仓（含 Token-2022），金额同时给出换算值与最小单位原始值。

## 什么时候用

- 想快速看清一个 Solana 地址上有多少 SOL、持有哪些代币。
- 对账时需要**最小单位的原始整数**，而不是钱包里四舍五入过的显示值。
- 怀疑某个代币在钱包里看得见、在别的工具里却查不到（多半是 Token-2022）。
- 想知道自己有多少个空的代币账户可以关闭，把租金取回来。

## 使用步骤

1. 选择**网络**（Mainnet Beta / Devnet / Testnet）。
2. （可选）填**自定义 RPC**。Solana 公共节点限流很紧，连续查询建议填自己的端点。
3. 粘贴**钱包地址**（base58 公钥），点**查询**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 网络 | Mainnet Beta / Devnet / Testnet |
| 自定义 RPC（可选） | 留空用公共节点 |
| 钱包地址 | Solana base58 公钥 |
| SOL | 换算后的 SOL，并附原始 lamports |
| 代币持仓 | Mint 地址、数量（换算值 + 最小单位）、所属程序 |

## 注意事项 & 常见坑

- **Token-2022 是单独一套程序**。Solana 上代币账户按程序区分，经典 SPL Token 与
  Token-2022 需要分别查询。本页两套都查 —— 只查一套的工具会**静默漏掉**一半持仓，
  而那些持仓在钱包里是看得见的。结果表里会用徽标标明每笔持仓属于哪一套。
- **数量同时给出两种形式**。换算值便于阅读，最小单位的原始整数才是链上事实。
  对账、发交易、写合约参数时请用原始值。
- **余额为 0 的代币账户不列出，但会报个数**。它们仍然占着租金（每个约 0.002 SOL），
  在钱包里关闭这些账户可以把租金取回来。不报这个数会让人以为自己没有这类账户。
- **这是只读查询**，不需要连接钱包，也不会要求任何私钥。
