# Solana 钱包生成（Generate Wallet）· Solana

> 本地生成 Ed25519 钱包（BIP39 助记词 + SLIP-0010 派生），也支持导入 Base58 私钥 / 助记词 / CLI JSON 数组还原。

## 什么时候用

- 需要一批 Solana 测试钱包做开发、测试或空投演练。
- 想用一条助记词按 SLIP-0010 路径派生多个地址，统一备份。
- 手上已有 Base58 私钥、助记词或 `id.json`，想还原出对应地址（及派生地址）。

> ⚠️ 助记词与私钥仅在本地内存中用于本次操作，**不上传、不存储、刷新即清除**。先读[安全模型](../security.md)。

## 使用步骤

### 方式一：随机批量生成

1. 选择**生成模式**：
   - **助记词派生**：一条 BIP39 助记词按 SLIP-0010 派生多个地址，备份这一条助记词即可恢复全部。
   - **各自独立**：每个钱包一条独立助记词，彼此无关联，需分别备份。
2. 选择**助记词长度**：12 / 15 / 18 / 21 / 24 词（词数越多熵越高）。
3. 设置**数量**（1–100）。派生模式下即沿路径连续派生的地址个数。
4. 点击**生成钱包**，结果表列出地址、私钥、助记词（默认打码）。

派生路径为 `m/44'/501'/i'/0'`（全 hardened，Phantom 系惯例）。

### 方式二：导入私钥 / 助记词

1. 在**导入**框粘贴：BIP39 助记词、Base58 私钥（64 字节 secretKey），或 Solana CLI 的 JSON 数组（`id.json`）。
2. 若导入的是助记词，可设置**助记词派生数量**（1–100）。
3. 点击**导入**还原对应钱包。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 生成模式 | `助记词派生` / `各自独立` |
| 助记词长度 | 12 / 15 / 18 / 21 / 24 词（BIP39） |
| 数量 | 1–100 |
| 派生路径 | `m/44'/501'/i'/0'`（全 hardened） |
| 导入内容 | 助记词 / Base58 私钥（64 字节 secretKey）/ CLI JSON 数组（`id.json`） |
| 输出 | 地址、私钥、助记词；地址导出、含私钥导出 |

## 注意事项 & 常见坑

- **路径惯例差异**：Phantom 系用 `m/44'/501'/i'/0'`，Solflare / Ledger / solana-keygen 常用 `m/44'/501'/i'`。若与自有钱包地址对不上，通常是路径差异所致。
- **数量上限 100**：一次最多派生 100 个地址。
- **私钥导入 ≠ 助记词派生**：直接导入的 Base58 私钥各自独立，不含派生信息。
- 结果**离开或刷新即丢失**，务必先导出或抄写保存。

## 安全提示

- 私钥 / 助记词默认打码，点击眼睛图标才显示，请在**安全环境**下查看与保存。
- **导出含私钥表格**会写出明文文件，任何人拿到都能完全控制这些钱包——导出后请妥善保管并及时删除。
- 敏感数据不写入 localStorage，关闭页面即从内存清除。
