# Polkadot 钱包生成（Generate Wallet）

> 本地生成 Substrate 钱包（BIP39 + SS58），或导入助记词 / 私钥；助记词与私钥不出本机。

## 什么时候用

- 需要一批 Substrate 测试钱包做开发、测试或演练。
- 想用一条 BIP39 助记词派生多个 Substrate 地址，统一备份。
- 手上已有助记词或 secret seed，想还原出对应地址。

> ⚠️ 助记词 / 私钥仅在内存中生成，不上传、不存储，刷新即清除；请离线备份，切勿泄露。先读[安全模型](../security.md)。

## 使用步骤

### 方式一：随机批量生成

1. 选择**密钥类型**：`ed25519` 或 `ecdsa`（`sr25519` 即将支持）。
2. 选择 **SS58 前缀**：Polkadot (0) / Kusama (2) / Substrate 通用 (42)，决定生成地址的前缀。
3. 选择**生成模式**：
   - **助记词派生**：一条助记词按索引派生多个账户。
   - **各自独立**：每个钱包一条独立助记词。
4. 选择**助记词长度**：12 / 15 / 18 / 21 / 24 词。
5. 设置**数量**（1–100）。
6. （可选）填**派生 URI**：留空且数量 > 1 时按 `//0` `//1` … 索引派生；填 URI（如 `//hard` 或 `///password`）则单账户派生。
7. 点击**生成钱包**，结果表列出地址与私钥（默认打码）。

### 方式二：导入助记词 / 私钥

1. 在**导入**卡的文本框粘贴 **BIP39 助记词**（可带 `//派生路径` `///密码`），或 32 字节 **secret seed**（`0x…`）。
2. 点击**导入**还原对应钱包。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 密钥类型 | `ed25519` / `ecdsa`（`sr25519` 即将支持） |
| SS58 前缀 | Polkadot (0) / Kusama (2) / Substrate 通用 (42) |
| 生成模式 | 助记词派生 / 各自独立 |
| 助记词长度 | 12 / 15 / 18 / 21 / 24 词（BIP39） |
| 数量 | 1–100 |
| 派生 URI（可选） | 如 `//hard` 或 `///password`；留空且数量 > 1 时按 `//0` `//1` … 索引派生 |
| 导入内容 | BIP39 助记词（可带 `//路径` `///密码`），或 32 字节 secret seed（`0x…`） |
| 输出 | 地址、私钥（默认打码）；支持导出地址、导出含私钥 |

## 注意事项 & 常见坑

- **密钥类型与主流钱包不同**：Polkadot 生态钱包默认用 sr25519 派生；本工具当前仅 ed25519 / ecdsa，同一助记词在此生成的地址与主流钱包（sr25519 默认）不同，**请勿据此核对或接收资产**。
- **数量上限 100**：一次最多生成 100 个钱包。
- **派生 URI 说明**：留空且数量 > 1 走 `//0` `//1` … 索引派生；填 URI 则单账户派生（sr25519 的 soft 派生即将支持）。
- **SS58 前缀只影响地址文本**：底层 AccountId 不变，换前缀不等于换账户。
- 结果**离开或刷新即丢失**，务必先导出或抄写保存。

## 安全提示

- 私钥 / 助记词默认打码，点击眼睛图标才显示，请在**安全环境**下查看与保存。
- **导出含私钥表格**会写出明文文件，任何人拿到都能完全控制这些钱包，导出后请妥善保管并及时删除。
- 敏感数据不写入 localStorage，关闭页面即从内存清除。
- **助记词 / 私钥不出本机**：全部在浏览器本地生成，不上传、不存储。
