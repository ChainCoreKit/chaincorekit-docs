# NFT 发行 / 铸造（NFT Issuance）

> 部署一个源码可查、可在 Sourcify 验证的标准 ERC-721，设置 Base URI，并向指定地址铸造 NFT。

## 什么时候用

- 想快速上线一个标准 ERC-721 系列，不写 Solidity 也能部署合约。
- 已有一个已部署的 ERC-721 合约，需要图形化设置 Base URI 或继续铸造。
- 测试网上验证发行流程（部署 → 设 URI → 铸造 → 预览）后再上主网。

## 使用步骤

1. 连接右上角钱包。未连接时写操作显示**「🔒 连接钱包后可用」**，点击即可拉起连接弹窗。
2. 在**合约**卡片选择一种方式：
   - **部署新合约**：填**名称**、**符号**；如果你上传的元数据文件名带 `.json`（如 `0.json`），勾选**元数据文件名带 .json 后缀**。部署网络跟随钱包当前所连的链。下方**部署预检**展示合约类型、**合约权限**、部署网络、预估费用与余额是否充足；点**查看合约源码**可看合约全文与编译参数。点**部署合约**进入确认弹窗，核对后**确认并部署**，弹窗展示 pending → 成功（合约地址 + 交易哈希）/ 失败（失败原因）。成功后可点**在 Sourcify 验证源码**（合约信息卡上也有同一个按钮）。
   - **导入已有合约**：选网络、填**合约地址**，点**导入合约**。
3. 部署或导入成功后，**合约信息**卡展示地址、名称、符号、标准、网络、已铸造数量，并提供复制地址与区块浏览器链接。
4. **设置 Base URI**：填 `ipfs://…/` 或 `https://…/metadata/`，查看预估费用后点**设置**。
5. **铸造 NFT**：填**接收地址**（可点「使用我的地址」），可选填**Token URI**（留空则用 Base URI 拼接），查看预估费用后点**铸造 NFT**。
6. **交易历史**卡按类型、交易哈希、Token ID、状态记录每一笔部署 / 铸造。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 名称 / 符号 | ERC-721 的 Name / Symbol |
| 元数据文件名带 .json 后缀 | 决定 tokenURI 的拼法：`Base URI + tokenId` 或 `Base URI + tokenId + .json`，**部署后不可修改** |
| 网络 | 跟随钱包当前所连的链 |
| 合约地址（导入） | `0x…`，已部署的 ERC-721 合约 |
| Base Token URI | `ipfs://…/` 或 `https://…/metadata/` |
| 接收地址 | `0x…`，接收 NFT 的地址 |
| Token URI（可选） | 单个 Token 的元数据 URI，留空用 Base URI 拼接 |
| 输出 | 合约地址、交易哈希、Token ID、交易状态 |

## 注意事项 & 常见坑

- **两级门控**：写操作需 ① 钱包已连接 ② 已部署或导入合约；未满足时对应卡片显示空状态引导，而非假数据。
- **网络一致性**：部署 / 铸造前核对「部署网络」与「钱包当前网络」一致，避免发到错误链。
- **tokenURI 怎么拼，页面会按合约实际情况告诉你**：
  - 本工具部署的合约：`Base URI + tokenId`，部署时勾了 `.json` 就是 `Base URI + tokenId + .json`；tokenId 从 0 开始。
  - 本工具**旧版模板**部署的合约：所有 NFT 的 tokenURI 都是 `Base URI + metadata.json`，**共用同一份元数据**。导入这类合约时页面会明确提示。
  - 其它来源的合约：以对方实现为准，常见为 `Base URI + tokenId` 或再加 `.json`。
- **合约权限**：部署钱包成为 owner，可以铸造、可以随时修改 Base URI（也就是修改全部 NFT 的元数据）、可以转移或放弃所有权；合约**没有暂停功能**，owner 无法冻结持有人的转账。
- **签名前切换了网络会被拦下**：确认之后、钱包签名之前换了链，交易不会发出，页面提示切回原网络再试。
- **验证会把源码发给 Sourcify**（公开的源码验证服务，结果对所有人可见）。Etherscan 需单独验证：下载 Standard JSON，在 Etherscan 的「Verify & Publish」页面选择 *Standard JSON Input* 提交。旧版模板的源码未公布，用它部署的合约无法补验证。
- **末尾斜杠别漏**，这是这一步最常见的错。填 `ipfs://Qm…` 而不是 `ipfs://Qm…/`，拼出来是 `ipfs://Qm…0` 而不是 `ipfs://Qm…/0` —— **每一枚的元数据都会取不到**，钱包和市场上全是空图，而改回来要再发一笔交易、再花一次 Gas。填写框下方会实时显示**拼出来的第一个 tokenURI**（形如 `tokenURI(0) → …`），发交易前照着它看一眼就能发现：它显示的是真实拼接结果，不会替你补斜杠。
- **导入合约需自检**：建议在区块浏览器核对该合约是否已验证，再进行写操作；ABI 来源不可信要留意风险。
- **各链原生币不同**：Ethereum/Arbitrum/Base = ETH，Polygon = POL，Sepolia = SepoliaETH，Gas 费用按对应原生币计。
- **费用为预估值**：预检与确认弹窗的费用为估算，实际以钱包最终签名时为准。

## 安全提示

- 部署与铸造是**真实上链且不可逆**的写操作，签名前务必核对网络、名称/符号、接收地址与费用。
- 高危操作（如转移合约所有权）应格外谨慎，建议二次确认。
- 大批量铸造前，先在测试网（Sepolia）走通完整流程再上主网。
