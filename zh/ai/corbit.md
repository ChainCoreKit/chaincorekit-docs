# Corbit AI 助手

> 内置的 AI 助手。用**你自己的** OpenAI 兼容端点与 API Key，浏览器直连。

## 什么时候用

- 看不懂某段 calldata、某个报错、某个 ABI 字段，想就地问一句。
- 想让它解释当前工具页在做什么，而不必切出去搜。
- 已经有 OpenAI / DeepSeek / Moonshot / 阿里百炼等任一家的 Key，不想再注册一个新账号。

Corbit **不自带模型也不自带额度**——它是个客户端，用量与费用都记在你自己的 Key 上。

## 配置

1. 点右下角悬浮球打开 Corbit，进入设置。
2. 填 **API 端点**。可以只填域名，会自动补 `/v1`；Azure 等路径特殊的端点请填完整地址。
3. 填 **API Key**。
4. 点获取模型，从列表里选一个；也可以直接手填模型名。

| 厂商 | 端点示例 |
| --- | --- |
| OpenAI | `https://api.openai.com/v1` |
| DeepSeek | `https://api.deepseek.com/v1` |
| Moonshot | `https://api.moonshot.cn/v1` |
| 阿里百炼 | `https://dashscope.aliyuncs.com/compatible-mode/v1` |

## Key 放在哪里

- **只存在你自己的浏览器里**（localStorage），不上传、不同步。
- 请求默认**从浏览器直接发往你填的端点**，不经过本项目的任何服务器。
- 换设备要重新填一次——这是刻意的，Key 不做跨设备同步。

> 这条只覆盖 Corbit。钱包、助记词、私钥类工具全程本地计算，与网络无关。

## 一个例外：安全转发

有些端点不允许浏览器跨域调用，而这个限制**只能由端点自己解除**，前端绕不过去。遇到这种端点时，Corbit 会自动改走一层安全转发并重发，你通常只会看到它正常回复，输入框下方多一行「安全转发中」。

此时 Key 会经过那层转发——它只用于当次请求，不存储、不记录。**这行提示不能忽略**：产品承诺是「Key 只在本机与你的端点之间」，转发发生时这句话不再完全成立，所以必须让你看得见。

大厂端点（OpenAI / DeepSeek / Moonshot / 百炼）都支持直连，不会触发转发。

详见[端点跨域（CORS）配置](./corbit-cors.md)。

## 注意事项

- **它会答错。** 链上操作前请自行核对地址、金额、网络，不要照着 AI 的回答直接签名。
- **不要把私钥或助记词贴给它。** 那会连同对话一起发到你的端点（以及可能的转发层）。任何情况下都没有必要这么做。
- 对话不落库，刷新页面即清空。
