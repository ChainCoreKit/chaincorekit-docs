# 私钥归集 · Sweep（Sweep）

> 把多个钱包的原生币或 ERC-20 代币，一键归集到指定的接收地址。

## 什么时候用

- 空投/测试后，把散落在多个钱包里的资产集中到一个主地址。
- 批量清空一组测试钱包的余额。
- 需要按「发送全部 / 固定数量 / 保留余额」不同策略统一归集。

> ⚠️ 源钱包私钥仅在本地内存中用于本次操作，**不上传、不存储、不出本机**。先读[安全模型](../security.md)。

## 使用步骤

1. 选择**数据来源**：
   - **跟随钱包**：使用当前已连接钱包所在网络。
   - **自定义 RPC**：填入 RPC 节点 URL，自动识别 ChainId。
2. 填写**接收地址**（归集到此地址）。
3. 填写**代币**：留空＝归集原生币；填 `0x…` ERC-20 合约地址＝归集该代币。
4. 选择**归集方式**：
   - **发送全部**：扣除预留 Gas 后把余额全部发走。
   - **固定数量**：每个钱包发送指定数量。
   - **保留余额**：每个钱包保留指定数量，其余发走。
5. 在底部文本框粘贴**源钱包私钥**（`0x` + 64 位十六进制，每行一个，可批量粘贴），点击**导入私钥**。
6. 导入后表格列出各地址与余额；可**刷新余额**、勾选/反选/删除行、按地址**筛选**。
7. 点击**一键批量归集**，在确认弹窗核对归集网络、接收地址、资产、方式、参与钱包数、预留 Gas 合计与预计归集总额后执行。失败行可**重试**（会先逐笔问链上，见下面专门一节）。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 数据来源 | 跟随钱包 / 自定义 RPC |
| 接收地址 | `0x…`，归集目标 |
| 代币 | 留空＝原生币；`0x…`＝ERC-20 合约地址 |
| 归集方式 | 发送全部 / 固定数量 / 保留余额 |
| 源钱包私钥 | `0x` + 64 位十六进制，每行一个 |
| 输出 | 各行状态、预计归集总额、导出结果 |

## 重发失败行：会先问链上

**「失败」有两种，后果差很远**：一种是根本没发出去（钱包里拒签、余额不够、估 Gas 失败），
另一种是**已经广播出去了，只是没等到确认回执**——主网拥堵时后者很常见。
对第二种直接重发，就是把同一个钱包再扫一遍：上一笔到账之后，第二笔要么把刚到账的 Gas 也带走，
要么因余额不足白烧一笔。链上没有撤销。

所以点重发之后，会先**逐笔去链上问**每一行到底怎么了，再决定发不发。你会看到：

- **「分诊中 3/12」的进度**：这是在串行查询，行数多时要等一会儿，旁边有停止按钮；
- **有些行点了不会重发**，这是有意的：
  - 链上其实已经成功 → 状态直接改回成功，不再发；
  - 交易仍在路上（节点收到了、还没打包）→ 跳过，等一会儿再看；
  - 交易被节点丢弃（多半是 Gas 出价过低）→ 解除锁定并清掉哈希，**再点一次**才真的重发；
  - 查不到状态（节点限流 / 网络故障）→ 不下结论、不重发，换个节点稍后重试。

另外两种情况也会被拦下：

- **在钱包里取消 / 顶替过的交易，记为失败**。钱包发出的「取消」本身是一笔会成功上链的交易，
  所以不能因为它成功就认为归集成功——那个钱包的钱一分没动。
- **换了网络、资产或接收地址之后重发会被拦住**，并提示改回原来的。因为一次归集的身份由这三样共同决定：
  在 A 链上失败的一笔，在 B 链上重发就是一次全新的归集，扫的还是另一种币；
  接收地址改了更是直接把钱扫去了另一个人那里。改回原来的再点即可正常重发。

## 注意事项 & 常见坑

- **预留 Gas**：归集原生币时需为每个钱包保留 Gas，「发送全部」实际发出的是「余额 − 预留 Gas」。
- **原生币 vs 代币**：归集 ERC-20 不消耗代币做 Gas，但源钱包仍需有原生币付 Gas，否则该行会失败。
- **接收地址务必核对**：归集不可逆，地址填错资产将无法找回。
- **网络一致性**：自定义 RPC 的 ChainId 要与你预期的链一致，避免发到错误网络。
- 各链原生币/计价币不同：Ethereum/Arbitrum/Base/Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。

## 安全提示

- 私钥文本框默认打码，点击眼睛图标才显示，请在**安全环境**下操作。
- 私钥仅用于本次签名，不写入 localStorage，关闭页面即从内存清除。
- 大批量操作前，建议先用 1–2 个钱包小额验证流程。
