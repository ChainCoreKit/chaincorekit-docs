# Disperse 合约分发（Disperse）

> 用 Disperse 合约在一笔交易里向多个地址分发原生币或 ERC-20，省 Gas、少签名。

## 什么时候用

- 一次给很多地址转账，想把多笔合并成一笔交易，节省 Gas、减少确认次数。
- 空投、批量发薪、活动奖励等一对多分发场景。
- 相比逐笔发送，更在意整体效率与签名次数。

## 使用步骤

1. 连接右上角钱包。未连接时按钮显示**「🔒 连接钱包后可用」**，点击即可拉起连接弹窗。
2. 顶部**发送网络**跟随当前钱包所在网络；卡片展示当前使用的 **Disperse 合约**地址（可复制、可跳区块浏览器）。
3. 填**代币**：留空＝原生币；填 `0x…` ERC-20 合约地址＝分发该代币。
4. 分发 ERC-20 时需先点**① 授权 Approve**，授权 Disperse 合约划转你的代币。
5. 录入名单：每行「地址,金额」（逗号 / 空格分隔），点**添加**；也可用**示例**、**导入 Excel / CSV** 或下载**模板**。
6. 表格可勾选 / **反选** / **删除选中** / **清空**，并按地址**筛选**。
7. 点**一键分发**，在确认弹窗核对发送网络、付款地址、分发资产、Disperse 合约、收款人数、预估 Gas 与分发总额后执行。结果可**导出**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 发送网络 | 跟随当前连接钱包所在网络 |
| 代币 | 留空＝原生币；`0x…`＝ERC-20 合约地址 |
| Disperse 合约 | 卡片展示的分发合约地址（可跳浏览器核对） |
| Approve | 分发 ERC-20 前的授权步骤 |
| 名单 | 每行「地址,金额」，逗号 / 空格分隔 |
| 输出 | 分发结果、导出 |

## 注意事项 & 常见坑

- **ERC-20 需先 Approve**：未授权无法分发；授权额度不足会失败，按提示先完成 ① 授权 Approve。
- **一笔交易上链**：分发在单笔交易内完成，只需一次签名，但整体 Gas 随收款人数增加。
- **付款钱包需有原生币付 Gas**：分发原生币时，总额之外还要预留 Gas。
- **核对 Disperse 合约地址**：写操作前建议在区块浏览器核对合约，确认为可信的分发合约。
- **金额精度**：ERC-20 金额按代币 `decimals` 换算。
- **各链原生币不同**：Ethereum/Arbitrum/Base/Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。
