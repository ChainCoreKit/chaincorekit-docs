# 余额批量查询（Balance Checker）

> 批量查询大量地址的原生币或 ERC-20 余额，跟随钱包或自定义 RPC，支持 Multicall。

## 什么时候用

- 手上有一大批地址，想一次性查出各自的原生币或某个代币余额。
- 空投前后核对名单余额，或监控一组钱包的资产状况。
- 想用 Multicall 聚合查询，减少 RPC 请求、加快批量速度。

## 使用步骤

1. 选择**数据来源**：**跟随钱包**（用当前连接钱包所在网络）或**自定义 RPC**（填 RPC URL，自动识别 ChainId）。
2. 填**代币**：留空＝原生币；填 `0x…` ERC-20 合约地址＝查询该代币余额（会显示代币信息）。
3. 设置参数：**预设**（普通 / 极速）、**并发数**；勾选 **Multicall** 后可设**每批**数量与**自定义 Multicall 地址**。
4. 录入地址：每行一个，或用逗号 / 空格分隔，点**添加**；也可用**示例**、**导入 Excel / CSV** 或下载**模板**。
5. 表格可勾选 / **反选** / **删除选中** / **清空**，并按地址**筛选**。
6. 点**开始查询**批量获取余额；失败行可**重查失败行**，结果可**导出**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 数据来源 | 跟随钱包 / 自定义 RPC（自动识别 ChainId） |
| 代币 | 留空＝原生币；`0x…`＝ERC-20 合约地址 |
| 预设 / 并发数 | 普通 / 极速；同时发起的查询条数 |
| Multicall | 聚合查询开关，可设每批数量与自定义合约地址 |
| 地址名单 | 每行一个，或逗号 / 空格分隔 |
| 输出 | 各地址余额、状态、失败重查、导出结果 |

## 注意事项 & 常见坑

- **只读工具**：查询不发交易、不需签名，无需私钥。
- **Multicall 自动回退**：开启后会检测该链是否部署 Multicall3（`eth_getCode`）；未部署则自动改用逐地址并发查询。
- **默认 Multicall3 多链同址**：`0xcA11bde05977b3631167028862bE2a173976CA11`；自定义地址前可点「检测」核对。
- **并发别过高**：并发数 / 每批过大可能触发 RPC 限速；用自定义 RPC 时注意节点承载。
- **金额精度**：ERC-20 余额按代币 `decimals` 换算展示，别把原始 Wei 数当人类可读数值。
- **各链原生币不同**：Ethereum/Arbitrum/Base/Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。
