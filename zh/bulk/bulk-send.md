# 钱包逐笔转账（Per-wallet Send）

> 用当前连接的钱包，逐笔签名逐个转出原生币或 ERC-20，无需任何合约、完全自控。

## 什么时候用

- 给一批地址各转一笔，想每笔都在钱包里单独确认、完全掌控。
- 不想依赖分发合约（不做 approve、不信任第三方合约）。
- 名单不大或金额各异，逐笔发送即可满足。

## 使用步骤

1. 连接右上角钱包。未连接时按钮显示**「🔒 连接钱包后可用」**，点击即可拉起连接弹窗。
2. 顶部**发送网络**跟随当前钱包所在网络。
3. 填**代币**：留空＝原生币；填 `0x…` ERC-20 合约地址＝发送该代币（会显示代币信息）。
4. 在底部文本框录入名单：每行一条「地址,金额」（逗号 / 空格分隔），点**添加**；也可点**示例**、**导入 Excel / CSV**，或下载**模板**按格式填好再导入。
5. 表格列出各行地址与金额，可勾选 / **反选** / **删除选中** / **清空**，并按地址**筛选**。
6. 点**逐笔发送**，在确认弹窗核对发送网络、付款地址、资产、收款人数、预估 Gas 与转账总额后执行。
7. 每笔单独在钱包确认并逐个上链；失败行可点**重发失败行**，结果可**导出**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 发送网络 | 跟随当前连接钱包所在网络 |
| 代币 | 留空＝原生币；`0x…`＝ERC-20 合约地址 |
| 名单 | 每行「地址,金额」，逗号 / 空格分隔 |
| 导入 | Excel / CSV，或按模板填写后导入 |
| 输出 | 各行状态、失败重发、导出结果 |

## 注意事项 & 常见坑

- **逐笔独立**：每笔都需在钱包单独确认，名单较大时确认次数多，追求少签名可用 [Disperse 合约分发](./disperse.md)。
- **付款钱包需有原生币付 Gas**：发送 ERC-20 也要用原生币付 Gas，余额不足该笔会失败。
- **金额精度**：ERC-20 金额按代币 `decimals` 换算，别把原始 Wei 数当人类可读数值。
- **地址务必核对**：转账不可逆，地址填错资产无法找回。
- **各链原生币不同**：Ethereum/Arbitrum/Base/Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。
