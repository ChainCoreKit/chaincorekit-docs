# 私钥批量转账（Multi-key Send）

> 导入私钥钱包，按批次并发发送原生币或 ERC-20，支持失败重试与自定义 Gas。

## 什么时候用

- 手上有一批私钥钱包，需要从某个钱包向大量地址批量发款。
- 名单很大，想用并发批次提高吞吐、失败自动重试。
- 需要自定义 Gas Limit、批量大小与最大重试次数。

> ⚠️ 私钥与助记词仅在本地内存中用于本次操作，**不上传、不存储、不出本机**。先读[安全模型](../security.md)。

## 使用步骤

1. 选择**数据来源**：**跟随钱包**（用当前连接钱包所在网络）或**自定义 RPC**（填 RPC URL，自动识别 ChainId）。
2. 在私钥框粘贴**私钥**（`0x` + 64 位十六进制，每行一个，可批量粘贴），点**导入私钥**；可点眼睛图标显示 / 隐藏。
3. 导入后从**发送钱包**下拉框选择用哪个钱包发款。
4. 填**代币**：留空＝原生币；填 `0x…` ERC-20 合约地址＝发送该代币。
5. 设置参数：**批量大小**（并发条数）、**最大重试**、**Gas Limit**（原生币约 21k）。
6. 录入收款名单：每行「地址,金额」（逗号 / 空格分隔），点**添加**；也可用**示例**、**导入 Excel / CSV** 或下载**模板**。
7. 点**批量发款**，在确认弹窗核对发送网络、发送钱包、资产、收款人数、批量 / 重试、Gas Limit、预估 Gas 与转账总额后执行。失败行可**重发失败行**，结果可**导出**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 数据来源 | 跟随钱包 / 自定义 RPC（自动识别 ChainId） |
| 私钥 | `0x` + 64 位十六进制，每行一个 |
| 发送钱包 | 从已导入私钥中选一个作为付款方 |
| 代币 | 留空＝原生币；`0x…`＝ERC-20 合约地址 |
| 批量大小 / 最大重试 / Gas Limit | 并发条数 / 重试上限 / 单笔 Gas 上限 |
| 名单 | 每行「地址,金额」，逗号 / 空格分隔 |
| 输出 | 各行状态、失败重发、导出结果 |

## 注意事项 & 常见坑

- **发送钱包需有原生币付 Gas**：发送 ERC-20 也要用原生币付 Gas，余额不足对应行会失败。
- **Gas Limit 要匹配操作**：原生币约 21k，发送 ERC-20 需更高，Gas Limit 过低会导致交易失败。
- **并发别过高**：批量大小过大可能触发 RPC 限速；用自定义 RPC 时尤其注意节点承载。
- **金额精度**：ERC-20 金额按代币 `decimals` 换算。
- **地址务必核对**：转账不可逆，地址填错资产无法找回。
- **各链原生币不同**：Ethereum/Arbitrum/Base/Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。

## 安全提示

- 私钥框默认打码，点眼睛图标才显示，请在**安全环境**下操作。
- 私钥仅用于本次签名，不写入 localStorage，关闭页面即从内存清除。
- 大批量操作前，先用 1–2 个地址小额验证流程再放量。
