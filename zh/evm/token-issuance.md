# Token 发行（Token Issuance）

> 创建并部署标准可铸造 ERC-20，部署前预检 Gas 与余额，确认后再签名；也可导入已有合约铸造。

## 什么时候用

- 想在测试网 / 主网快速发一个标准 ERC-20 Token。
- 已部署过某个 ERC-20，想导入后继续铸造。
- 部署前想先看清预估费用、部署网络与钱包余额是否充足。

## 使用步骤

### 部署新合约

1. 先在右上角**连接钱包**（未连接时按钮显示「🔒 连接钱包后可用」，点击即拉起连接）。
2. 在**部署新合约**标签填写**名称 / 符号 / 发行总量 / 精度 Decimals**，并选择**网络**。
3. 查看**部署预检**：合约类型、初始发行、部署网络、钱包当前网络、预估费用、余额是否充足。
4. 点**部署合约**，在确认弹窗核对信息后**确认并部署**；随后弹窗展示 pending → 成功 / 失败，成功后可复制合约地址、交易哈希并跳区块浏览器。

### 导入已有合约

1. 选择**网络**，在**导入已有合约**标签填入 **Token 合约地址**。
2. 点**导入合约**，之后按 ERC-20 标准交互。

### 铸造 Token

- 部署或导入合约后，在**铸造 Token** 卡片填**接收地址**（可点「使用我的地址」）与**数量**，查看预估费用后点**铸造**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 名称 / 符号 | Token 名称与符号（如 ChainCore Token / CCK） |
| 发行总量 | 初始发行数量 |
| 精度 Decimals | 小数位；多数为 18，USDC / USDT 等稳定币常用 6 |
| 网络 | Ethereum / Arbitrum One / Base / Polygon / Sepolia |
| 部署预检 | 合约类型、发行、网络、预估费用、余额校验 |
| 合约信息 | 部署 / 导入后展示地址、名称、符号、精度、总供应、网络 |
| 铸造 | 接收地址 + 数量，展示预估费用 |
| 交易历史 | 交易类型 / 交易哈希 / 状态 |

## 注意事项 & 常见坑

- **两级门控**：写操作需先①连接钱包、②满足业务前置（已部署 / 已导入合约），缺一按钮不可用。
- **部署 / 铸造是真实上链交易**，会消耗 Gas 且不可逆，确认前务必核对网络、发行量与账户。
- **网络与原生费用币对应**：Ethereum / Arbitrum One / Base = ETH，Polygon = POL，Sepolia = SepoliaETH；预估费用按所选网络计。
- **精度影响数量含义**：`decimals=18` 时链上以最小单位记账，别把原始数值当人类可读数量。
- **导入前先核对**：确认地址与所选网络无误，建议在区块浏览器核对该合约是否已验证再做写操作。
- 高危写操作前会二次确认，请仔细阅读弹窗信息。
