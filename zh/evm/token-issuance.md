# Token 发行（Token Issuance）

> 部署一个源码可查、可在 Sourcify 验证的标准 ERC-20；部署前预检 Gas、余额与合约权限，确认后再签名；也可导入已有合约铸造。

## 什么时候用

- 想在测试网 / 主网快速发一个标准 ERC-20 Token。
- 需要一个**能在区块浏览器 / Sourcify 上核对源码**的代币合约，方便持币人与合作方确认它不含后门。
- 已部署过某个 ERC-20，想导入后继续铸造。

## 使用步骤

### 部署新合约

1. 先在右上角**连接钱包**（未连接时按钮显示「🔒 连接钱包后可用」，点击即拉起连接）。部署网络**跟随钱包当前所连的链**，要换网络请在钱包里切换。
2. 在**部署新合约**标签填写**名称 / 符号 / 发行总量**，按需填写**最大供应量**（留空表示不设上限）。
3. 查看**部署预检**：合约类型、**合约权限**、初始发行、部署网络、预估费用、余额是否充足。
4. 想看部署的到底是什么，点**查看合约源码**：页面展示合约全文与编译参数（OpenZeppelin 版本、solc 版本、优化次数、EVM 版本）。
5. 点**部署合约**，在确认弹窗核对信息后**确认并部署**；弹窗展示 pending → 成功 / 失败。
6. 部署成功后，点**在 Sourcify 验证源码**，几秒到几十秒内出结果；成功后可点**在 Sourcify 查看**。合约信息卡上也有同一个按钮，关掉弹窗后随时可以验证。

### 导入已有合约

1. 在**导入已有合约**标签填入 **Token 合约地址**，点**导入合约**，之后按 ERC-20 标准交互。

### 铸造 Token

- 部署或导入合约后，在**铸造 Token** 卡片填**接收地址**（可点「使用我的地址」）与**数量**，核对参数回显后点**铸造**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 名称 / 符号 | Token 名称与符号（如 ChainCore Token / CCK），符号 1–12 位字母或数字 |
| 发行总量 | 按**整枚数**填写，部署时全部铸给部署钱包 |
| 最大供应量（可选） | 按整枚数填写；留空 = 不设上限。不能小于发行总量，**部署后不可修改** |
| 精度 Decimals | 本工具部署的合约固定为 18，不可修改 |
| 部署预检 | 合约类型、合约权限、发行、网络、预估费用、余额校验 |
| 合约信息 | 地址、名称、符号、精度、总供应、最大供应量、网络 |
| 铸造 | 接收地址 + 数量；回显同时给出换算后的最小单位原值 |
| 交易历史 | 交易类型 / 交易哈希 / 状态 |

## 合约权限（部署前请看清）

- **部署钱包成为 owner**，只有 owner 能铸造。
- **没设最大供应量时，owner 可以无上限增发**；设了上限，增发总量永远不能超过它（销毁后腾出的额度可以再铸回来）。
- 任何持有人都可以销毁自己的代币。
- owner 可以转移或放弃所有权；**放弃后再也无法铸造**。

这些都写在预检的「合约权限」一行里，也能在源码里逐行核对。

## 注意事项 & 常见坑

- **两级门控**：写操作需先①连接钱包、②满足业务前置（已部署 / 已导入合约），缺一按钮不可用。
- **签名前切换了网络会被拦下**：确认之后、钱包签名之前如果你在钱包里换了链，这笔交易不会发出，页面会提示切回原网络再试——同一个地址在另一条链上可能是完全不同的合约。
- **部署 / 铸造是真实上链交易**，会消耗 Gas 且不可逆，确认前务必核对网络、发行量与账户。
- **铸造前要先读到代币精度**：导入的代币精度可能是 6、8 等。精度读取失败时铸造按钮不可用，并提示「重新读取」——按错误精度铸造会铸出完全不同的数量，且无法撤回。
- **验证会把源码发给 Sourcify**：Sourcify 是公开的源码验证服务，结果对所有人可见。Etherscan 需要单独验证：点**下载 Standard JSON**，在 Etherscan 的「Verify & Publish」页面选择 *Standard JSON Input* 提交。
- **旧版模板部署的合约不能补验证**：本工具早期模板的源码未公布，之前部署的合约照常可以导入、铸造，但无法在 Sourcify 验证。
- **部署失败分三种，处置方式不同**，结果弹窗会分别给出原因：
  - **钱包拒签** —— 交易没发出去，没花 Gas，改完参数直接重来即可；
  - **发送失败**（余额不足、RPC 报错等）—— 同样没上链，按提示的原因处理；
  - **部署回滚 · 构造函数执行失败** —— 交易**已经上链并消耗了 Gas**，但那个地址上没有代码，需要修正参数后重新部署。
- **各链原生币不同**：Ethereum / Arbitrum One / Base / Optimism = ETH，BNB Chain = BNB，Polygon = POL，Avalanche = AVAX，Sepolia = SepoliaETH。
