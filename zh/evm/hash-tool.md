# Hash 工具（Hash Tools）

> 对输入字符串实时计算 keccak-256 / SHA3-256 / SHA-256，或做 Base64 / Hex 编码，切换算法即时重算。

## 什么时候用

- 计算函数选择器 / 事件 TopicID / EIP-55 用到的 keccak-256。
- 需要通用哈希 SHA3-256、SHA-256 对字符串做摘要。
- 把字符串做 Base64 或 Hex(UTF-8) 编码。

## 使用步骤

1. 在顶部选择算法：**keccak-256 / SHA3-256 / SHA-256 / Base64 / Hex(UTF-8)**。
2. 在**输入内容**框填入待计算的字符串。
3. **结果**实时显示在下方，点复制按钮复制；切换算法即时重算。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 算法 | keccak-256 / SHA3-256 / SHA-256 / Base64 / Hex(UTF-8) |
| 输入内容 | 任意字符串（按 UTF-8 处理） |
| 结果 | 对应算法的哈希或编码输出，可复制 |

## 注意事项 & 常见坑

- **keccak-256 ≠ SHA3-256**：以太坊用的是 keccak-256，与标准化后的 SHA3-256 结果不同，别混用（算选择器 / TopicID / EIP-55 用 keccak-256）。
- **输入按字符串处理**：这里对文本按 UTF-8 计算，不是对 hex 字节数组求哈希，注意区分。
- **Base64 / Hex 是编码不是哈希**：可逆、不用于摘要或校验。
- 所有计算在本地完成，输入不上传。
