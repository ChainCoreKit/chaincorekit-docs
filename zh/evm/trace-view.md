# 交易分析（Transaction Tracer）

> 解析 EVM 交易的内部调用栈，展示概览、CallTraces、资金流向、资产变化、事件日志与 Gas 分析，支持地址 / 函数别名映射。

## 什么时候用

- 想看清一笔交易内部到底调用了哪些合约、发生了什么。
- 交易 revert 了，想定位在哪一层调用失败、失败原因是什么。
- 需要梳理一笔交易的资金流向、资产净收支、触发的事件与各调用 Gas 占比。

## 使用步骤

1. 选择交易所在的**网络**（Ethereum / Arbitrum One / Base / Optimism / BNB Chain / Polygon / Avalanche / Sepolia）。
2. 在输入框粘贴**交易哈希**，点**分析**；也可点**成功示例 / 失败示例**快速体验。
3. （可选）展开**高级 · 别名映射**，把调用栈里的 `0x` 地址 / 函数选择器显示成可读名字（如 `WETH.deposit()`），可点**填入示例**或分「地址映射 / 函数映射」手动填。
4. 查看结果：**交易概览**、**CallTraces**（可全部折叠）、**资金流向**、**资产变化**、**事件日志**、**Gas 分析**；概览处可**在区块浏览器打开**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 网络 | 决定别名库与区块浏览器链接，与钱包当前连接网络无关 |
| 交易哈希 | `0x` + 64 位 hex |
| 别名映射 | 地址 / 函数 → 可读名字，仅影响展示、不影响分析 |
| 交易概览 | 基本信息与 revert 提示 |
| CallTraces | 内部调用树，revert 调用红色高亮并显示原因 |
| 资金流向 / 资产变化 | Fund Flow 图 + 各地址净收支 |
| 事件日志 / Gas 分析 | Emitted Events 与各调用 Gas 占比 |

## 注意事项 & 常见坑

- **网络只影响别名库与浏览器链接**，与钱包当前连接的网络无关，别选错链。
- **别名映射仅影响展示**：把 `0x` 编码换成可读名字，不改变分析结果；悬停可查看原始 `0x` 值。
- **revert 会红色高亮**并展示原因，逐层查看即可定位失败调用。
- **动态类型 / 复杂结构**在调用栈里可能只按原始编码展示，可结合别名与 Calldata 工具进一步解读。
