# 测试币水龙头（Faucets）

> 按网络汇总各测试网水龙头，一键复制 Chain ID、把网络添加到钱包，并直达领取入口。

## 什么时候用

- 开发 / 测试合约需要测试币，想快速找到对应测试网的水龙头。
- 手上有新钱包地址，想为它领取 SepoliaETH、tBNB、AVAX 等测试币。
- 想把某条测试网一键添加到钱包，省去手动填 RPC / Chain ID。

## 使用步骤

1. 用顶部搜索框按**网络 / 货币 / 关键词**实时筛选（如 `Sepolia`、`ETH`），或点标签在**全部 / 以太坊测试网 / L2 / 侧链 / 其他**间切换。
2. 在目标网络卡片上，可**复制 Chain ID**，或点**添加到钱包**把该网络加入钱包。
3. 点卡片上的**展开**按钮，查看该网络下的水龙头列表。
4. 每条水龙头显示域名、门槛标签与备注；点**领取 ↗** 在新标签打开该水龙头，或点复制按钮复制其网址。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 搜索框 | 按网络名 / 货币 / 关键词实时过滤 |
| 标签筛选 | 全部 / 以太坊测试网 / L2 / 侧链 / 其他 |
| Chain ID | 每条测试网的链 ID，可一键复制 |
| 货币 | 该测试网原生测试币（SepoliaETH / tBNB / AVAX / POL 等） |
| 门槛标签 | 免登录 / 需登录 / 需连接钱包 / 需挖矿 / 需主网余额 |
| 领取入口 | 外链跳转到第三方水龙头，或复制其网址 |

## 注意事项 & 常见坑

- **只是导航，不代发币**：水龙头由第三方提供，实际发放规则、限额、冷却时间以对方页面为准。
- **门槛差异大**：部分水龙头需登录 / 连接钱包 / PoW 挖矿，甚至要求主网有余额，领取前先看门槛标签。
- **仅测试币无价值**：测试网代币不可在主网使用，也没有真实价值，切勿用于任何资产交易。
- **网络已覆盖 11 条**：包含 Sepolia、Hoodi、Polygon Amoy、Optimism / Arbitrum Sepolia、Aurora、BNB Chain Testnet、Avalanche Fuji、Gnosis Chiado、Harmony Testnet、Celo Alfajores。缺少的水龙头可提交 ISSUE / PR。
