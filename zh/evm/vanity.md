# 靓号地址（Vanity Address）· EVM

> 在浏览器本地碰撞生成带指定前缀 / 后缀的 EVM 地址，私钥不出本机。

## 什么时候用

- 想要一个好记、带辨识度的地址（如以 `dead` 开头、`beef` 结尾）。
- 需要携带特定标识的地址用于品牌 / 合约展示。
- 想在本地生成靓号，不把私钥交给任何在线服务。

## 使用步骤

1. 在**前缀 Prefix**（`0x` 之后）与**后缀 Suffix**（地址结尾）填入想要的 hex 字符，可只填其一。
2. （可选）勾选**大小写敏感（EIP-55 校验和）**：开启后按大小写精确匹配，难度更高；关闭则忽略大小写、命中更快。
3. 界面会按规则给出难度提示；点**开始生成**启动本地碰撞。
4. 在**生成进度 / 结果**卡片查看进度与速度，命中后展示靓号地址与对应私钥；可随时点**停止**。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 前缀 Prefix | `0x` 之后的起始字符，hex（0-9 a-f），可留空 |
| 后缀 Suffix | 地址结尾字符，hex，可留空 |
| 大小写敏感 | 开：按 EIP-55 大小写精确匹配；关：忽略大小写 |
| 难度提示 | 按规则估算命中难度 |
| 输出 | 命中的地址 + 私钥，以及碰撞进度 / 速度 |

## 注意事项 & 常见坑

- **难度指数增长**：前缀 / 后缀每多一位，期望尝试次数约翻 16 倍；开启大小写敏感后字母位难度再翻倍。位数越多，等待时间可能极长。
- **只接受 hex 字符**：地址由 0-9、a-f 组成，`g`、`z` 等非法字符无法作为靓号目标。
- **纯本地碰撞**：地址在浏览器内实时生成，不联网求解，速度取决于本机性能。
- **结果不持久**：私钥仅本次显示，离开或刷新页面即丢失，命中后请立即复制 / 抄写保存。

## 安全提示

- **私钥 100% 本地生成，永不离开本机**，不上传、不存储。
- 命中的私钥请在**安全环境**下查看与保存；任何拿到私钥的人都能完全控制该地址。
- 敏感数据不写入 localStorage，关闭页面即从内存清除。
