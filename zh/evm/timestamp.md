# 时间戳换算（Timestamp Converter）

> Unix 时间戳与日期双向互转：贴入时间戳得到 UTC / ISO 8601 / 本地时间，或选一个日期反查时间戳。秒与毫秒自动识别。

## 什么时候用

- 合约里的 `block.timestamp`、`deadline`、锁仓到期时间、vesting 起止时间，想知道对应的是哪一天几点。
- 构造交易参数（如 swap 的 `deadline`、permit 的过期时间）时，需要某个日期对应的秒级时间戳。
- 拿到一串 13 位数字，不确定它是秒还是毫秒。

## 使用步骤

### 时间戳 → 日期

1. 在**时间戳**输入框填入数值（可带千分位逗号或下划线）。
2. 输入框下方会标出这次是按**秒**还是按**毫秒**解析的。
3. 结果给出 UTC、ISO 8601、本地时间，以及对应的秒级 / 毫秒级时间戳，每行都可一键复制。

点右上角的**取当前时间**可把两侧同时填成此刻。

### 日期 → 时间戳

1. 在**日期时间**里选择日期与时刻（按你当前设备的时区理解）。
2. 下方给出秒级、毫秒级时间戳与对应的 UTC 时间。

## 输入 / 输出说明

| 输入位数 | 解析为 | 典型来源 |
| --- | --- | --- |
| ≤ 11 位 | 秒 | 链上 `block.timestamp`、合约参数、多数后端接口 |
| ≥ 12 位 | 毫秒 | JavaScript `Date.now()`、部分前端埋点 |

## 注意事项 & 常见坑

- **链上时间一律以秒计**。把毫秒值直接填进合约参数不会报错，只会变成几万年之后 —— 例如 `deadline` 永不过期。
- **反过来把秒当毫秒**会落到 1970 年 1 月，同样不报错。看一眼输入框下方的「按秒 / 按毫秒解析」提示即可避免。
- 「日期 → 时间戳」按**本地时区**理解你选的时刻；需要 UTC 整点时，对照结果里的 UTC 一行核对。
- 只接受十进制纯数字；`0x` 开头的十六进制值会提示格式错误，需先转成十进制再填。
