# 地址转换与 ENS（Address & ENS）

> 本地实时生成 EIP-55 校验和地址（keccak-256），并对 ENS 域名做智能正 / 反向解析。

## 什么时候用

- 拿到一个全小写地址，想转成带大小写的 EIP-55 校验和格式。
- 想校验一个地址的 checksum 是否正确、格式是否合法。
- 想把 ENS 域名解析成地址，或反过来把地址解析成域名。

## 使用步骤

### 地址格式转换

1. 在**地址**输入框粘贴 `0x` + 40 位 hex 地址（示例：vitalik.eth = `0xd8dA…6045`）。
2. 实时输出 **EIP-55 校验和**与**全小写**两种形式，点复制按钮即可复制。

### ENS 智能解析

1. 在输入框填入 **ENS 域名或地址**，工具自动识别类型。
2. 输入 `.eth` 域名 → 正向解析出地址；输入地址 → 反向解析出域名，结果可复制。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 地址 | `0x` + 40 位十六进制，实时校验 |
| EIP-55 校验和 | 按 keccak-256 生成大小写混合的规范地址 |
| 全小写 | 地址的全小写形式 |
| ENS 输入 | `.eth` 域名或 `0x` 地址（自动识别） |
| 解析结果 | 域名 → 地址（正向）/ 地址 → 域名（反向） |

## 注意事项 & 常见坑

- **EIP-55 靠大小写编码校验和**：改动任意字母的大小写都会让校验失败，复制时不要改动大小写。
- **校验和本地用 keccak-256 生成**，不联网、不上传地址。
- **ENS 解析当前为本地词典**：仅收录示例域名（如 `vitalik.eth`、`nick.eth`），不代表链上实时解析结果。
- 地址是 hex，只含 0-9、a-f；非法字符会即时报错。
