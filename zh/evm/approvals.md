# 授权管理（Token Approvals）· EVM

> 查你指定的 Token 与 spender 的当前授权额度，并可就地撤销。

## 什么时候用

- 用完某个 DApp，想把给它的授权收回来。
- 做完批量分发 / 归集，想确认给合约的授权额度是不是还挂着。
- 想确认某个地址对某个 Token 的授权到底是多少、是不是无限额度。

## 使用步骤

1. 选**网络**。
2. 填**持有者地址**（留空则用当前连接的钱包）。
3. 每行填一对 **Token 地址 + spender 地址**，空格或逗号分隔，最多 20 行。
4. 点**查询授权**。Token 类型会自动探测：ERC-721 走 `isApprovedForAll`，其余按 ERC-20 读 `allowance`。
5. 若你就是持有者本人且钱包在对应网络上，有效授权那一行会出现**撤销**按钮。

## 输出说明

| 情况 | 显示 |
| --- | --- |
| ERC-20 有额度 | 按 decimals 换算后的数值 |
| ERC-20 无限授权 | `∞ · 无限额度`（标红） |
| ERC-721 已全量授权 | `已授权全部（setApprovalForAll）`（标红） |
| 读取失败 | 明确标注失败，不显示 0 |

## 注意事项 & 常见坑

- **本工具不做全量发现。** 这是最重要的一条：普通 RPC 没有「列出某地址全部授权」这个方法，全量发现需要扫历史 `Approval` 事件或接索引服务。所以**这里查不到东西，只说明你填的那几对没有授权**——不代表这个地址没有其他授权，更不代表安全。工具不会、也不应该给出"未发现风险"这种结论。
- **无限授权按量级判定。** 不同项目写的"无限"不完全一样（`type(uint256).max`、`2^255`、`uint96` 上限……），精确等值判断会漏掉一大半。因此这里把超过 `2^255` 的一律显示为 `∞`——宁可把一个巨大但有限的额度也标成无限，也不要把真正的无限授权印成一串数字，让人误以为可控。
- **Permit2 有额外一层。** 把 Token 授权给 Permit2 之后，实际支出许可记在 Permit2 内部，用这里的 ERC-20 撤销**清不掉那一层**。要撤销 Permit2 内部的许可，得到对应协议自己的界面操作。
- **只有本人能撤销。** 查询任意地址都可以，但撤销需要用持有者本人的钱包签名。查别人的地址时不会出现撤销按钮。
- **ERC-20 与 ERC-721 的 `Approval` 事件 topic0 完全相同**，光看事件分不出类型，所以这里用 `supportsInterface` 主动探测。

## 撤销的完整流程

撤销是写操作，按项目统一约定执行：**参数预览 → 钱包签名 → 等待确认 → 结果**。未连接钱包时按钮显示「连接钱包后可撤销」（点击即拉起连接），钱包在错误网络时显示「切换网络」——任何情况下都不会在未确认前发出交易。
