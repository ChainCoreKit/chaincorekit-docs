# 生成钱包（Generate Wallet）· EVM

> 本地批量生成 EVM 钱包，支持助记词派生，也支持用已有私钥/助记词导入创建。

## 什么时候用

- 需要一批测试钱包做开发、测试或空投演练。
- 想用一条助记词按 BIP44 路径派生多个地址，统一备份。
- 手上已有私钥/助记词，想还原出对应地址（及派生地址）。

> ⚠️ 私钥与助记词仅在本地内存中用于本次操作，**不上传、不存储、不出本机**。先读[安全模型](../security.md)。

## 使用步骤

### 方式一：随机批量生成

1. 选择**生成模式**：
   - **同一助记词派生（HD）**：一条 BIP39 助记词派生多个地址，备份这一条助记词即可恢复全部；某个私钥泄露只影响对应地址。
   - **各自独立助记词**：每个钱包一条独立助记词，彼此无关联，需分别备份。
2. 选择**助记词长度**：12 / 15 / 18 / 21 / 24 词（词数越多熵越高）。
3. 设置**数量**（≤ 100）。HD 模式下即从推导路径连续派生的地址个数。
4. （可选）展开**高级 · 推导路径**，调整 `account`、起始 `index`，也可填写 BIP39 passphrase。路径遵循 BIP44：`m / 44' / 60' / account' / 0 / index`。
5. 点击**立即生成**，结果表列出地址、私钥、助记词（默认打码）。

### 方式二：自定义私钥 / 助记词创建

1. 切到**自定义私钥 / 助记词创建**标签。
2. 在文本框输入私钥或助记词，**一行一个**，可批量粘贴。
3. 点击**立即创建**还原对应钱包。

> 通过私钥导入时，无法使用「派生地址数量」「推导路径」等 HD 高级选项（私钥本身不含派生信息）。

> **BIP39 passphrase（选填）**：又称「第 25 个词」。留空即标准派生；一旦填写，
> 同一条助记词会派生出**完全不同、且互不相通**的一组钱包。写错一个字符不会报错，
> 只会安静地给出别的地址；请与助记词**分开保管**，丢失后仅凭助记词无法找回资产。

## 输入 / 输出说明

| 项 | 含义 / 格式 |
| --- | --- |
| 生成模式 | `同一助记词派生` / `各自独立助记词` |
| 助记词长度 | 12 / 15 / 18 / 21 / 24 词（BIP39） |
| 派生地址数量 | 1–100 |
| 账户 Account | BIP44 路径中的 `account'`，默认 0 |
| 起始 index | BIP44 路径末段起始值，默认 0 |
| 导入内容 | 私钥（`0x` + 64 位十六进制）或 BIP39 助记词，一行一个 |
| 输出 | 地址、私钥、助记词、推导路径；支持复制、导出、二维码详情 |

## 注意事项 & 常见坑

- **数量上限 100**：一次最多派生 100 个地址。
- **二维码只含地址**，可安全用于接收测试币；**切勿**生成私钥二维码。
- **私钥导入 ≠ HD 派生**：导入的私钥各自独立，不能再设派生数量/路径。
- 结果**离开或刷新即丢失**，务必先导出或抄写保存。

## 安全提示

- 私钥/助记词默认打码，点击眼睛图标才显示，请在**安全环境**下查看与保存。
- **导出含私钥表格**会写出明文文件，任何人拿到都能完全控制这些钱包——操作前会二次确认，导出后请妥善保管并及时删除。
- 敏感数据不写入 localStorage，关闭页面即从内存清除。
